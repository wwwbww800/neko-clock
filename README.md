
# Neko Chronos
想找個好看的時鐘放在副螢幕? 你來對地方了<br>
這是Neko Chronos 一個貓娘版網頁時鐘<br>

## 特色
時鐘本身就是一隻貓娘 她會根據早中晚不同的時段和你打招呼<br>
如果你只想看時間不想被打擾 右上角按一下就能把她「消音」隱藏 介面會瞬間變回極簡狀態<br>
有串天氣 API 會顯示你所在地的氣溫（根據IP定位 可手動輸入地址）<br>
點齒輪設定可以換介面顏色主題 也能切 12/24 小時制 設定都會自動存在瀏覽器裡<br>
