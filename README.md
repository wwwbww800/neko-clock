
# Neko Chronos
想找個好看的時鐘放在副螢幕? <br>
這是Neko Chronos 一個網頁時鐘(貓娘版)<br>

## 功能/特色
時鐘本身就是一隻貓娘 會根據早中晚不同的時段和你打招呼<br>
有串天氣 API 會顯示你所在地的氣溫（根據IP定位 可手動輸入地址）<br>
點齒輪設定可以換介面顏色主題 也能切 12/24 小時制 設定都會自動存在瀏覽器裡<br>
設定內也可以隱藏貓娘問候和天氣<br>
